# Translazor by RicoDEV

Welcome to **Translazor** – your fun and experimental translator tool made by **RicoDEV**! 🚀

This project was created as a fun way to explore translation mechanics while offering a neat solution for translation tasks. If you're here, you're probably looking for a light-hearted, easy-to-use tool that can help you with translation – or maybe you're just here for the fun of it. Either way, you're in the right place! 😄

---

## Features

- **Client-Server Translation**: You can easily communicate between the client and server for fast translation operations.
- **Easy Configuration**: Configure the translation logic with simple JSON files. No crazy setups required.
- **Encryption Fun**: With some crypto magic thrown in, this tool adds a fun twist to how we handle translation data. (Don't worry, it's not *too* serious!)
- **Modular Setup**: Everything is designed to be extendable! Whether you're just looking for a simple translation or want to experiment with different components, this setup's got you covered.

---

## How To Run

1. Clone or download this repository.
2. Open the `Client` folder and run the `main.py` script.
3. The server logic can be found in the `Server` folder, where you can tweak things as you see fit.
4. If you're ready for the *complete experience*, you can run both the client and the server at the same time using `runboth.bat` to have a smooth translation flow.
